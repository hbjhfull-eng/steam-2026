# 디지털로 읽는 중화 반응 — STEAM 융합수업

고등학교 1학년 **통합과학 · 정보 · 수학 융합교육(STEAM)** 프로그램
「디지털로 읽는 산과 염기의 중화 반응」의 **학생 모집 페이지 + 50분 × 4차시 웹 활동지**입니다.

* 정적 HTML 두 파일 — 빌드 과정 없음
* 외부 의존성은 Google Fonts CDN 하나뿐, 오프라인이면 시스템 글꼴로 대체
* 학생 입력은 **각자 기기의 브라우저(localStorage)** 에만 저장 — 서버·수집 없음
* 다크 모드 · 모바일 대응 · 인쇄(PDF) 최적화

## GitHub Pages 배포 방법

### 1. 저장소 만들기

GitHub에서 새 저장소를 만듭니다. 이름은 자유이며, 예시는 `neutralization-steam` 입니다.
(이름을 바꾸면 위 미리보기 주소의 마지막 경로도 그 이름으로 바뀝니다.)

### 2. 파일 올리기

**A. 웹에서 드래그로 올리기 (가장 간단)**

1. 저장소 페이지 → **Add file → Upload files**
2. 이 폴더의 `index.html`, `favicon.svg`, `.nojekyll`, `LICENSE`, `README.md` 를 끌어다 놓기
   (`.nojekyll` 은 확장자가 없어 안 올라갈 때가 있으니, 안 되면 **Create new file** 로
   파일명에 `.nojekyll` 만 입력해 빈 파일로 커밋)
3. **Commit changes**

**B. git 명령으로 올리기**

```bash
cd neutralization-steam
git init
git add .
git commit -m "학생 활동지: 디지털로 읽는 중화 반응 (4차시)"
git branch -M main
git remote add origin https://github.com/<사용자명>/neutralization-steam.git
git push -u origin main
```

### 3. Pages 켜기

1. 저장소 **Settings → Pages**
2. **Build and deployment → Source** 를 **Deploy from a branch** 로
3. **Branch** 를 `main` / `/ (root)` 로 지정하고 **Save**
4. 1\~2분 뒤 상단에 게시 주소가 표시됩니다.

### 4. 업데이트

파일을 고쳐 다시 커밋/푸시(또는 웹에서 다시 업로드)하면 1분 내외로 자동 반영됩니다.

## 모집 단계 사용법

1. `index.html` 의 `〔  〕` 항목과 구글 폼 주소를 채우고 커밋
2. 배포 주소(`…/neutralization-steam/`)를 QR·가정통신문·클래스룸으로 공유
3. 학생은 페이지에서 과정을 확인하고 **[구글 폼으로 신청하기]** 로 지원

## 수업 단계 사용법 (활동지)

1. `…/neutralization-steam/activity.html` 주소를 공유
2. 학생은 **각자 기기**에서 접속 → 상단에 학번·이름·모둠 입력
3. 차시별(1\~4 버튼)로 이동하며 빈칸·표·체크리스트 작성 (입력 자동 저장, 진행률 표시)
4. 제출은 **[답안 복사]** (정리된 텍스트가 클립보드로) 또는 **[인쇄 · PDF]**

> localStorage 저장이므로 **다른 기기·시크릿창·브라우저 데이터 삭제 시 내용이 사라집니다.**
> 차시 사이에 기기가 바뀌면 그때그때 [답안 복사]로 보관하도록 안내하세요.

## 수업 구성 (4차시)

| 차시 | 주제 | 교과 | 학생 핵심 활동 |
|---|---|---|---|
| 1 | 산과 염기의 중화 반응 | 통합과학 | 성질표 · 알짜 이온 반응식 · **자바실험실** 이온 수 변화표 |

| 3 | 중화 반응 실험 & 데이터 수집 | 통합과학 · 데이터 | 회차별 전도도 측정 · 스프레드시트 그래프 · V자 해석 |
| 4 | 지오지브라로 함수 모델링 | 통합과학 · 공통수학 | 절댓값 함수 `y=a\|x−p\|+q` · 예측 · 중화열 함수 확장 |

# 활동지 제출 기능 설정 (교사 1회 작업, 약 10분)

학생이 활동지 맨 위 **[제출하기]** 버튼을 누르면 모둠 답안이 교사의 구글 시트에 자동으로 저장됩니다.
모둠 대표가 **주제 마지막에 한 번** 제출하며, 같은 모둠명으로 다시 제출하면 그 행이 최신 내용으로 덮어써집니다.

## 1. 구글 시트 만들기
1. 구글 드라이브에서 새 **구글 스프레드시트**를 만들고 이름을 `STEAM 융합수업 제출함`으로 정합니다.
2. 이 시트는 학생과 공유하지 마세요. (학생은 시트를 열 필요가 없습니다.)

## 2. 코드 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
2. 기본으로 있는 `function myFunction() {}` 를 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣습니다.
3. (선택) 제출 코드를 쓰려면 맨 위 `var SUBMIT_CODE = "";` 의 따옴표 안에 코드를 적습니다. 예: `"steam26"`
4. 저장(💾)합니다.

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 설정:
   - 설명: `STEAM 제출`
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포**를 누르면 권한 승인 창이 뜹니다. 본인 계정을 선택 → "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트명)으로 이동 → 허용**.
5. 표시되는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 4. 사이트에 연결
`submit-config.js` 의 `endpoint` 에 복사한 주소를 붙여넣고 GitHub에 푸시합니다. (Claude에게 주소를 알려 주면 대신 처리합니다.)
제출 코드를 쓸 경우 `needCode: true` 로도 바꿉니다.

```js
window.STEAM_SUBMIT = {
  endpoint: "https://script.google.com/macros/s/.../exec",
  needCode: false
};
```

푸시 후 1~2분 뒤부터 4개 활동지에 [제출하기] 버튼이 나타납니다.

## 5. 반드시 해 볼 것 (시험 제출)
1. 활동지를 열어 몇 칸 채우고 **[제출하기] → 모둠명 `테스트`** 로 제출합니다.
2. 시트에 `주제N …` 탭이 생기고 한 행이 들어왔는지 확인합니다. `제출로그` 탭에도 기록됩니다.
3. 확인 후 테스트 행은 지웁니다.

## 시트 보는 법
- 주제별 탭: 모둠당 1행. `답안 전문` 칸을 클릭하면 위쪽 수식 입력줄에서 전체 내용을 읽을 수 있습니다.
  (읽기 편하게 하려면 그 칸을 복사해 메모장·문서에 붙여넣으세요.)
- `제출횟수`가 2 이상이면 재제출한 모둠입니다. 이전 버전이 필요하면 `제출로그` 탭의 시각을 참고하세요.
- `원본(JSON)` 칸은 데이터 분석용이라 보지 않아도 됩니다.

## 코드를 수정한 경우
Code.gs 를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 반영됩니다.
(웹앱 URL은 그대로 유지됩니다.)

## 주의
- 웹앱 주소는 사이트 소스에 공개됩니다. 소규모 교내 활동에는 충분하지만, 외부 장난 제출이 걱정되면 `SUBMIT_CODE` 를 쓰세요.
- 이름이 시트에 저장되므로 학교 개인정보 지침에 맞게 관리하고, 학기 종료 후 시트를 삭제·보관 처리하세요.
- 무료 계정 기준 하루 수천 건까지 문제없어 이 규모에서는 한도 걱정이 없습니다.

# 세특 근거 폼 만들기 (선택, 1회 실행)

활동지 제출(모둠 단위)과는 별도로, **학생 개인의 세특 근거**를 모으기 위한 구글 폼 6개
(활동 전/중/후 × 개인/모둠)를 자동으로 만드는 기능입니다. 실행 한 번이면 폼 6개와 응답을 모을
새 스프레드시트가 한 번에 만들어집니다.

## 1. 새 스크립트 프로젝트 만들기
1. [script.google.com](https://script.google.com) 접속 → **새 프로젝트**.
2. 프로젝트 이름을 `STEAM 세특 폼 생성기` 로 바꿉니다.
   (제출용 `STEAM 제출 수신기` 프로젝트와는 별개로 새로 만드는 것입니다 — 헷갈리지 않게 이름을 다르게 둡니다.)

## 2. 코드 붙여넣기
1. 기본 `function myFunction() {}` 를 모두 지웁니다.
2. 이 폴더의 `FormBuilder.gs` 내용을 통째로 붙여넣습니다.
3. **Ctrl+S** 로 저장합니다.

## 3. 실행
1. 코드 편집기 위쪽, **실행할 함수** 드롭다운에서 `buildAllForms` 를 선택합니다.
2. ▶ **실행** 버튼을 누릅니다.
3. 권한 승인 창이 뜨면: 본인 계정 선택 → "확인되지 않은 앱" 경고가 나오면 **고급 → STEAM 세특 폼 생성기(안전하지 않음)로 이동 → 허용**.
   (이 권한은 본인 드라이브에 폼·시트를 만들기 위한 것입니다.)
4. 실행이 끝나면(수 초~수십 초) 아래쪽 **실행 로그**에 새 스프레드시트 링크가 출력됩니다. 그 링크를 엽니다.

## 4. 확인 및 배부
1. 열린 스프레드시트 `STEAM 세특 근거 응답 모음` 첫 탭(`시트1`)에 폼 6개의 이름과 **학생에게 나눠줄 링크**가 정리되어 있습니다.
2. 폼 내용을 한 번씩 열어 검토하고, 필요하면 구글 폼 화면에서 문항을 자유롭게 고치거나 추가하세요. (이후 문항 수정은 Claude 없이 직접 하시면 됩니다.)
3. 학생에게는 이 6개 링크 중 해당 시점(전/중/후)·단위(개인/모둠)에 맞는 링크를 안내합니다. 사이트의 활동지나 안내장에 링크를 걸어 두면 편합니다.
4. 학생 응답은 폼별로 스프레드시트 안의 각 탭(폼 이름과 동일)에 자동으로 쌓입니다. 이름/번호로 정렬하거나 필터링해서 세특 작성 시 참고하세요.

## 주의
- 이 폼들은 **로그인 없이도 응답할 수 있게** 기본 설정되어 있습니다(제출 활동지와 동일한 방식). 응답자 확인이 필요하면 폼 설정에서 "이메일 수집"을 켜되, 그러면 학생이 구글 계정으로 로그인해야 응답할 수 있게 됩니다.
- `buildAllForms` 를 다시 실행하면 **폼 6개와 스프레드시트가 또 새로 만들어집니다.** (기존 것을 덮어쓰지 않음) 잘못 만들었을 때만 다시 실행하고, 이전 것은 드라이브에서 휴지통으로 보내세요.
- 학생 이름이 응답에 포함되므로 개인정보 처리 방침은 제출함 시트와 동일하게 적용하세요.
